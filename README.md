# Oleg

A universal AI development system based on **Streamlit + Ollama + local LLMs**

![License](https://img.shields.io/badge/license-MIT-blue)

---

## ❔How is it works?
You enter your prompt, and the first ai analyzes this prompt. It reformulates your prompt and divides it into the 2nd ai.
This AI can edit, create and delete your files.
---

For oleg you need to have installed ollama on your computer 
```bash
irm https://ollama.com/install.ps1 | iex
```
and before using 
```bash
ollama serve
```
